Detailed Description

Extracts the data from the UTIAS Multi-robot Localisaion and Mapping Dataset.

The class extracts the textfile dataset form UTIAS multi-robot localisation and mapping dataset into three members: Data::Handler::barcodes_, Data::Handler::landmarks_, and Data::Handler::robots_.

◆ calculateGroundtruthMeasurement()

void Data::Handler::calculateGroundtruthMeasurement ( )
private

Calculates the ground truth measurements for a given robot.

The following expression is utilised to calculate the groundtruth measurement values using the groundtruth robot state values extracted from the dataset:

\[\begin{bmatrix} r_{ij}^{(k)} \\ \phi_{ij}{(k)} \end{bmatrix} = \begin{bmatrix} \sqrt{(x_i^{(k)} - x_j^{(k)})^2 + (y_i^{(k)} - y_j^{(k)})^2} \\ \text{atan2}(y_j^{(k)} - y_i^{(k)}, x_j^{(k)} - x_i^{(k)}) - \theta_i^{(k)}\end{bmatrix}, \]

where \(i\) denotes the ego robot; \(j\) denotes the measured robot; \(k\) denotes the current time step; \(\theta\) denotes the robot's orientation; and \( y\) denotes the robot's y-coordinate.

◆ calculateGroundtruthOdometry()

void Data::Handler::calculateGroundtruthOdometry ( )
private

Utilises the extracted robots groundtruth position and heading values to calculate their associated groundtruth odometry values.

The following expression is utilsed to calculate the groundtruth odomotery values using the groundtruth states values extracted from the dataset:

\[\begin{bmatrix} \omega_k \\ v_k \end{bmatrix} = \begin{bmatrix} \text{arctan2}(\sin(\theta_{k+1} - \theta_{k}), \cos(\theta_{k+1} - \theta_{k})) / \Delta t \\ \sqrt{(x_{k+1} - x_k)^2 + (y_{k+1} - y_k)^2} \end{bmatrix}, \]

where \(k\) denotes the current time step; \(\theta\) denotes the robot's orientation; \( y\) denotes the robot's y-coordinate; \(\Delta t\) is the user defined sample period; \(\omega\) and \(v\) denotes the angular velocity and forward velocity of the robot respectively.

◆ setDataSet()

void Data::Handler::setDataSet ( const std::string &  dataset,
const std::string &  output_directory = HandlerDefaults::kOutputDir,
const double &  sample_period = HandlerDefaults::kSamplePeriod 
)

Extracts data from the all files in the specified dataset folder.

Parameters
[in]datasetdataset path to the dataset folder.
[in]sample_periodthe desired sample period for resampling the data to
[in]output_directoryThe directory where the extracted data and plots are saved. sync the timesteps between the vehicles.
Note
All datasets in the UTIAS Multi-robot Localisation and mapping dataset have the same number of landmarks and robots. Therefore, if the dataset directory is provided, it is assumed that the number of landmarks and robots will be 5 and 15 respectively. The number of barcodes is the summation and these two values.
The function only checks the existence of the given datset folder. The data extraction is performed by calling the functions: Data::Handler::readBarcodes, Data::Handler::readLandmarks, Data::Handler::readGroundTruth, Data::Handler::readOdometry, and Data::Handler::readMeasurements. Additionally, the Data::Handler::syncData function is called to resample to data points through linear interpolation to ensure all robots have the same time stamps.
